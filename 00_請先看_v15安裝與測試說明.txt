KD Coffee Studio v15.0.0 Developer Edition

這是以完整 v14.0 LTS 為基礎整理的完整專案，不是 PATCH。

重要變更
1. 顧客不登入 LINE 也能選商品、加入購物車與結帳。
2. LINE Login 保留為選擇性便利功能。
3. 加強全站連結、作品卡、商品規格與購買按鈕的點擊／觸控層。
4. Launcher 更新時不再自動建立完整專案備份。
5. PATCH 更新只暫存本次修改檔案，成功後自動刪除。
6. 手動完整備份仍保留。

第一次啟動
1. 將整個資料夾解壓到新的位置，不要直接覆蓋唯一一份 v14。
2. 將舊專案的 .env.local 複製到新專案根目錄。不要把 .env.local 上傳或分享。
3. 若沒有 node_modules，使用 Launcher 執行 npm install。
4. 啟動網站。
5. 電腦瀏覽器按 Ctrl + F5；手機關閉舊分頁後重新開啟。

優先測試
- 首頁與導覽列連結
- /works 作品卡
- 商品規格、豆／粉與數量
- 加入購物車
- 立即購買
- 未登入 LINE 進入 Checkout 並送出測試訂單

注意
- 本環境無法替你的 Windows 電腦完成實際瀏覽器與 Launcher 啟動測試。
- 建議保留原本 v14 資料夾，確認 v15 測試正常後再切換。
